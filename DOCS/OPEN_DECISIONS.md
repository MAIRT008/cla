# 实施提案与待验证条件

> v1.3。已确认业务要求不在这里重开讨论。本表给出候选方案、比较依据和对应路径的验证节点；技术采用与发布参数须由实际证据确定。

## 1. 已确认，不再待定

模型服务配置在服务端、提示词在客户端；AI 主导精确清理并经用户确认执行；默认浏览器优先；Clash 内置；三模式固定 A/B；共享上游按用户独立限额；故障阻断和手动应急入口；无需全应用归属；程序统计与 AI 每日分析；首版不做隔离。

## 3. 建议数值与验收目标

以下数值是首轮测量的 RECOMMENDED 候选观察目标与试验参数，不是已跑出的性能或 Owner 已冻结的发布条款。包括 5 秒/64 MiB、8 次调用等在内，未达到建议值不自动淘汰成熟组件，也不要求为追逐建议值强改上游核心；先记录实际行为、影响和可用配置，再决定发布值及必要适配。改变建议须明示依据，不能改测试来假装通过；每用户服务端独立限额、A/B 同账、固定 A 故障阻断、确认后精确执行等已确认行为不得放宽。

| 项目 | 初始建议 | 验证与边界 |
|---|---|---|
| 个人月额度 | 后台可配置，示例 250 GB；1 GB = 1,000,000,000 bytes | 上传+下载，A/B合并，计量点只扣一次；不把 250 GB 和 250 GiB 混用 |
| 周期 | UTC 自然月，后台存精确 period_start/end，UI 显示本地重置时间 | 不使用电脑时钟重置；日报仍独立使用 America/Los_Angeles |
| 字节口径 | 以实际服务节点可核验的该用户上行+下行计数为准，包含其计量层可见开销 | 业务载荷与线路开销可能不同；先对 100 MiB 测试载荷实测并解释，不能承诺用户账与上游池账完全相等 |
| 超额停止 | 达阈值后拒绝新连接并中止/收尾在途连接；候选观察目标为生效 ≤5 秒、额外计量 ≤64 MiB | 在拟发布带宽和并发范围下记录实际时延与额外计量，再决定发布值和是否需配置/适配；不按建议值自动淘汰组件或强改上游核心，不无声增加额度，不退化客户端限额 |
| 用量提醒 | 80% / 95% / 100%，同一周期同级不重复打扰 | 上游池不足另报；用户可见同步时间 |
| 本机采样/配额显示刷新 | 本机约 1 秒，服务端快照约 30 秒 | 显示刷新不决定服务节点何时停用；短连接覆盖需单列 |
| 自动更新 | 每日检查，失败按有限退避重试；至少保留两个本地有效配置版本 | 已撤销版本不可恢复，A 绑定不因自动更新改变 |
| 应急上网 | 每次显式开启，默认 30 分钟，可主动延长 | 全程验证 Claude 仍受保护；超额时不绕过账目 |
| 深度扫描 | 10,000 个合成测试文件、1 GB 测试集合下，本地阶段目标 ≤60 秒；AI 阶段另计 | 首批目标，真实大目录注明规模；取消目标 ≤2 秒响应，不遍历全盘 |
| AI 单次扫描预算 | 候选试验预算：最多 8 次模型调用、总输入输出预算 64k tokens、单次响应超时 60 秒、全任务最长 5 分钟 | 试验明确采用的预算先到时返回已知结果；记录质量、成本和中断情况后决定发布预算，不能把调用上限当质量证明或用超出建议次数自动淘汰 SDK |
| AI 日报预算 | 一次脱敏汇总，失败自动重试最多 1 次，总预算 16k tokens | 保留标准报告；迟到内容是附注 |
| 方案切换 | 正常网络下目标 ≤15 秒完成应用与复查，否则显示仍在验证或失败 | 故障期间保持保护，不以超时自动宣告成功 |
| 当前异常到保护 | 以程序获得明确异常证据起算，目标 ≤1 秒发出保护；生效目标 ≤3 秒 | 同时记录系统生效结果；必须另测证据采集延迟，不能只测发指令速度 |
| 备份 | 默认保留 7 天、到期提示，不自动清掉身份/项目材料 | 敏感恢复包系统保护；用户能预览恢复冲突 |
| 归档/日报容量 | 归档默认保留 30 天、日报 90 天作为容量预警建议 | 首版到期仅提示；不自动删除当前窗口证据或历史日报，另行确认清理 |
| 小范围试用 | 建议 3—5 位同意参与的 Windows 用户，连续 5 个工作日观察 | 不需要为试用无限增加未来企业特性 |
