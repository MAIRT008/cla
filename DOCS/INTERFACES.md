# 逻辑接口与数据责任

> v1.3 · 供 P0/P1 实现对齐。以下名称是建议的内部契约，不是已经存在的 API 路径或可调用服务。

## 1. 通用约定

所有跨模块结果带 task_id、environment_ref、observed_at、source_version 和 evidence_refs。对象使用本地生成的 object_ref，完整路径留在客户端；模型不自由提交任意路径。时间保留 UTC 时间戳，展示时转换；日报另保留指定 IANA 时区。

状态表达 completed / partial / failed / cancelled / unsupported，缺失值使用 unknown 原因，不填零/正常。前端隐藏普通用户不需要的技术字段，详情和报告可追溯。

## 2. 客户端工具与确认

| 建议操作 | 输入 | 输出与边界 | 主要消费者 |
|---|---|---|---|
| DiscoverEnvironment | 用户选定范围与环境 | 客户端/目录/Profile/账号引用、覆盖缺口；不读取秘密值 | FD-01、FD-02 |
| InspectObject | 已发现 object_ref、字段/记录选择器、读取预算 | 脱敏片段、类型、引用关系、内容指纹；超范围拒绝 | AI 清理规划 |
| BuildActionPlan | scan_id、发现项、推荐操作 | plan_id、版本、每项前置条件/影响/保留项/备份与预期差异 | UI 确认页 |
| ConfirmActionPlan | 本地用户勾选和确认、plan_id/version | confirmed_actions、对象指纹、授权范围；不由模型伪造 | 执行器 |
| ExecuteConfirmedPlan | plan_id/version、已确认 action_ids、operation_id | 一次批量调用逐项检查/备份/执行/复查；返回逐项回执、恢复引用和汇总；重试跳过已成功项 | AI 编排或标准模式 |
| RecheckAction | action_id、预期差异与保护对象 | 实際读回差异、保留验证、剩余问题、时间 | 评分/AI/结果页 |
| RestoreChange | backup_ref、预览后的恢复确认、当前指纹 | 仅恢复自己修改的具体字段/对象；冲突暂停 | UI、执行器 |
| ApplyNetworkPlan | assignment_version、模式、白名单版本、授权引用 | downloaded/validated/applied/verified 分阶段状态 | FD-02、FD-03 |
| ReadNetworkState | 当前环境和观察范围 | 核心存活、加载版本、保护结果、计量快照、缺测 | FD-02、FD-04 |
| RequestEmergencyAccess | 用户本次确认、批准资源与隔离范围 | 独立应急状态、到期、路由验证；Claude 保护状态并列 | UI、网络服务 |

对象指纹变更→STALE_PLAN；不支持格式→UNSUPPORTED_FORMAT；占用→OBJECT_BUSY；权限不足→ACCESS_DENIED；范围扩大→OUT_OF_SCOPE；资源失效→RESOURCE_UNAVAILABLE。错误需有用户可理解的下一步，不能只显示代码。

写入顺序为：验证本次用户授权→检查目标仍在范围内且未变→生成适用恢复材料→执行精确操作→复查→记录。确认后的一次批量工具调用在本地执行这些步骤，不对每个文件都重新等待模型。每项保留稳定动作标识与回执；模型重试或取消后恢复时，已成功项不重复，未开始项只有在授权和前置条件仍有效时继续。相互依赖的动作按计划顺序执行；失败只允许不依赖该项的已确认动作继续。新增对象或动作重新形成计划并确认。未知数据库不能靠整库删除通过测试。

AI 允许请求读取和已确认执行，不允许 ConfirmActionPlan，也不允许提供裸 shell、任意 SQL、未知脚本或动态增加工具。SQLite 类清理只接受预定义适配器的明确记录条件；项目资料、正常账号和受保护日志仍经本地检查。边界在客户端代码内，不能只写在提示词里。

## 3. 模型调用

客户端请求：task_type（cleanup / network_diagnosis / daily_analysis）、prompt_version 与提示词正文、tool_catalog_version、脱敏必要事实、会话内工具结果。服务器认证本应用用户，选择服务器端提供方、模型、端点、密钥和预算；输出模型文本、结构化计划或工具调用请求，以及失败原因/用量。

客户端不接受服务器返回任意管理员命令。服务器不要求真实 Cookie、Token、代理密码或项目全文。提示词留在客户端指持久化与版本来源在客户端，实际调用时须传到服务器/模型，并非“永不离开客户端”。复用 SDK 时以本接口作为传输边界：客户端不决定实际模型端点、提供方、参数或密钥，不能原样接受 SDK 默认请求中的这些选择。小型工具循环与 Pi 的选择按实际适配量决定，复用现有后台，不另建 AI 控制服务。

建议 AI 请求超时、轮数与预算见 OPEN_DECISIONS；超限返回已有结果和缺口，不以无界重试消耗资源。模型配置未设好/额度不足时显示 AI 不可用，基础扫描与保护继续。服务端日志只记录任务引用、版本、耗量和错误码，默认不长期保存提示词及对象内容。

## 4. 受管配置发布与恢复

后台产生一份按用户分配的候选：用户/设备引用、允许模式、资源引用、最终 A/B 绑定、模板版本、分类映射版本、有效期、批准的基础通信范围。共享上游秘密按接入拓扑保存在服务节点，客户端只取得自身接入身份与必要配置。

客户端验证身份、版本、范围与资源后渲染一份生效配置，先保留当前有效版本，再应用并读取真实状态。配置文件写入不等于内核加载，更不等于路径验证成功。失败保留/恢复最近有效且未撤销的版本，保护仍在；没有有效版本时阻断相应代理。

期望版本与实际版本分别记录。白名单为该用户唯一存储，在切模式时启停，不复制三份。配置恢复不能回滚服务端配额或恢复已撤销凭据。网络服务串行处理普通配置写入，应急保护具备优先路径。若复用 CVR，产品输入直接接入收窄后的原配置生成/应用链；其 profile、merge/script 和刷新写入口按受管范围裁剪或改接，不能只隐藏界面后保留两套竞争的配置管理器。

## 5. 用户配额适配器

| 操作 | 必须给出的结果 |
|---|---|
| AllocateUserAccess | 独立服务身份、资源池、可用 A/B 路径，不泄露其他用户 |
| ReadUserUsage | user_ref、period_start/end、upload/download/used_bytes、limit_bytes、measured_at、口径与来源 |
| ChangeLimit | 生效额度与版本、服务节点实际回执，避免 UI 自行推定 |
| SuspendUserAccess | 指定用户新连接被拒、在途处理状态、实际生效时间；不能停整个共享上游 |
| ResumeUserAccess | 仅额度/授权有效时恢复原绑定；验证其他用户状态 |
| ReadPoolUsage | 共享上游剩余和来源时间；单独用于运营告警，不代替个人账目 |

由服务商原生计量或受管节点产生权威用量。后台只保存必要配置和查询快照，不用客户端上报重建第二本权威账。差异报告至少列时间、范围、单位、其他设备和重置，不由 AI 选一个数覆盖另一个。

## 6. 浏览器页面回传

客户端生成一次性诊断会话，打开默认浏览器中的诊断页。返回 session_ref、浏览器/Profile 的可证实信息、采样时间、脚本版本、实际 IP/DNS/WebRTC 等结果与失败项。采用本地回传时仅 loopback 监听、短期随机令牌和明确来源校验；页面不能调用清理或改网接口。远程探测只调用授权清单服务。

不能以 User-Agent 单独证明 Profile；需要用户选择或本地可证实关联。Chrome/Edge 不能通过受支持方式读取的设置应给出手动确认，不尝试全盘搜 Cookie 值补足身份。

## 7. 实时监测与报告

内核采集输出：连接标识、时间、字节数/增量、进程字段（如有）、目的字段（如有）、路由链、内核实例/重置标识。被动日志产生四类路由结果与解析缺口。采样遗漏不填成零流量。

归档输入只包含已批准日志源，输出哈希、来源、归档时间、成功/跳过/秘密例外。报告以唯一 report_id、日期、时区、左闭右开窗口、分类版本和来源集合生成；双格式必须有相同事实摘要。已有有效非空 MD/JSON 对即为交付，无论路由结论。

AI 只消费这份结构化统计的脱敏派生件，输出 fact_refs、解释、推断、待办、模型/提示词版本和状态。延迟附注引用 report_id，不覆盖原报告。紧急事件上报是独立通信，不能把归档/回放权限扩成联网改网。
