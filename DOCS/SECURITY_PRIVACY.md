# 数据、AI 工具与授权边界

> v1.2。按当前真实任务保护账号和项目资产；不新增独立权限平台。

## 1. 数据去向

| 数据 | 本地 | 本应用服务器/模型 |
|---|---|---|
| Claude Cookie、Token、密码、代理凭据、私钥 | 只由必要适配器读取/使用，显示存在性与掩码；敏感备份按用户权限保护 | 不发送给模型，不进入普通日志或导出 |
| 项目记录、记忆、配置 | 保护原件，必要时本地识别用途/关联 | 默认不发全文；先发送用途摘要或已授权的最小脱敏片段 |
| 清理对象与字段差异 | 完整精确定位留本地，供确认执行 | 使用 object_ref 和必要脱敏内容；不要求真实用户名和完整路径 |
| 提示词 | 源文件/版本在客户端 | 调用时发送本应用服务器再到模型；默认不作为服务器长期内容日志保存 |
| 模型端点、提供方、密钥与参数 | 客户端只看到服务状态/可用能力 | 服务器保存和选择，不回传密钥 |
| 原始访问日志、完整日报 | 默认留本地，按 FD-04 归档 | 日常只传必要汇总/最小事件；额外排障包须预览授权 |
| AI 每日分析材料 | 从标准报告生成脱敏摘要 | AI 数据授权范围内传输；不自动上传全域名历史 |
| 用户月配额 | 带来源时间的展示快照 | 服务节点为计量权威；后台保存配置和必要快照 |

秘密字段在模型输入构建前过滤，并在普通输出/导出前复检。若源日志意外含秘密，不原样复制到普通 raw；记录拒绝原因，若生成脱敏派生件则使用自己的哈希和来源引用，不声称与原件字节一致。

## 2. 三种操作授权

单次确认绑定具体对象与动作；首次常规维护授权覆盖明确的订阅/规则更新范围；紧急保护预授权覆盖当前危险情况下的明确断流动作。AI 的工具请求不能生成或扩大这些授权。

清理/系统设置修改仍经确认后执行。AI 主导规划和操作编排不等于后台能任意控制电脑。扫描、日志回放、评分和 AI 分析不能直接放开网络保护、换 A 或删除未勾选资料。

手动应急上网单独展示目标、资源、路由范围和期限。用户拒绝应急授权时继续当前保护，并保留本地诊断。

## 3. 最小执行面

文件操作保持当前用户权限，限已发现对象和固定类型的适配器；网络服务仅暴露内核生命周期、受管配置、保护/恢复与状态读取。不存在裸命令、任意 SQL、任意文件路径写入或任意下载执行入口。

客户端必须验证本地交互的用户、plan_id/version、动作白名单和对象现状。模型无法自行提交“用户已同意”。文本内嵌“忽略原规则”等内容只是数据；最终执行边界由程序控制。

配置和备份采用平台受限访问，必要秘密用系统加密保护；不在命令行、进程参数、普通日志或公共示例中暴露。版本备份不会恢复失效身份或回滚服务端账目。

## 4. 网络和后台

所有正常探测、模型请求、遥测和后台配置通信使用模板规定的路由。固定链不可用时不能临时创建未知直连来“帮助恢复”。首次 bootstrap 和故障支持访问需要在产品中明确，其范围与 Claude 业务分开。

共享上游凭据若能绕开个人计量点，不能下发给客户端。用户下载的个人配置必须受同一独立服务身份约束。超额、暂停、到期需在服务节点生效，不能只隐藏按钮。

后台管理权限仅涉及本应用用户与资源。用户标识、设备绑定、配额和事件需身份校验；首版使用现成认证与最小管理员角色即可，不扩展多级组织权限系统。

## 5. 本地验证与开源交付

测试目录、邮箱、账号标识、站点数据库、订阅及节点配置使用合成数据。真实网络/配额试验用明确授权的测试资源，不能中断 Owner 当前生产链来验收。

公开仓库不包含生产订阅、认证文件、真实 IP 分配和个人日志。原历史文档可留在本地参考，但公开发布前逐项检查。当前打包是本地交付，没有授予自动 push、发布或对外分享权限。

产品数据授权不等于本轮 Codex 获得本机清理许可。本轮只补方案，未实施任何上述产品操作。
