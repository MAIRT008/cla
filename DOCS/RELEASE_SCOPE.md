# 首版范围与跨文档修订

> 当前业务决定见 [决策依据](SOURCE_DECISIONS.md)。本页明确范围；具体流程见 [完整方案](V1_PLAN.md)。

## 1. 首版交付

首版覆盖 FD-01—04 的适用功能：AI 主导本地识别、精确清理与恢复；网络及真实浏览器检测、确认后处理；应用内 Clash、三套受管方案和共享上游下的用户配额；流量显示、即时保护、两小时归档与 AI 每日分析。标准模式、断网下可做的本地检查和已有恢复保留。

不引入隔离工作台、新装 WSL/Docker/虚拟机、独立浏览器引擎、账号池、商城、多层微服务或任意命令 Agent。管理端可以部署成熟配额组件；“客户端不要求 Docker”不代表后台部署方式已经由 Owner 限定。

## 2. 首批支持矩阵提案

以下是用于估时和先验收的 RECOMMENDED 矩阵，P0 用真实版本验证后固定具体版本号。未覆盖平台只说明边界，不假称已修好。

| 对象 | 首版处理 | 扩展条件 |
|---|---|---|
| Windows 11 x64、当前稳定更新 | 首批安装、服务、网络保护、清理、恢复完整验收 | Windows 10、ARM64、macOS/Linux 不计入本轮估时 |
| 官方 Claude Desktop / Claude Code | 标准安装入口和可识别自定义配置位置；固定版本样本中的文件、字段和账号关联 | 新格式先识别，解析器验证后增加写入适配 |
| 默认浏览器为 Chrome 或 Edge 稳定版 | 识别默认浏览器和实际使用 Profile；页面实测；经确认应用支持的专用设置 | 浏览器不默认切换；多 Profile 时只问一个简单选择；其他浏览器先只读/页面诊断 |
| 其他已发现 Profile | 列出范围与能识别的 Claude 资料，用户选择才深查 | 不为首版实现所有数据库版本的任意写入 |
| 已存在 WSL | 识别发行版、可访问 Claude 目录及覆盖缺口；用户主动授权才进一步扫描 | 不创建、重置、迁移发行版；不能把宿主 TUN 结果套给 WSL |
| CC Switch / 第三方 Claude 资料 | 检测引用、活跃配置与残留；支持格式按字段或记录处理 | 不能确定归属或安全粒度时保留并给出明确人工步骤 |
| 网络资源 | 一组已验证共享上游、每用户 A/可选 B、服务端独立身份和限额 | 增加供应商是适配任务，不预建通用供应商平台 |
| 应用用户和设备 | 建议首版每用户一台受管 Windows 设备；测试同时使用和重装的账目保持 | 多设备若启用必须服务端合并，不额外给额度 |

这不是削减四模块，只限定实际承诺的平台和格式。核心路径不得用“未支持”绕过：默认浏览器、正常/受限账号、混合项目配置、三套模式、共享订阅用户限额和紧急保护均须有真实可用路径。

## 3. 跨文档当前口径

| 原来的表达 | 当前口径 |
|---|---|
| AI 只读、模型部署待定 | 扫描阶段只读；AI 主导计划并调用客户端工具执行已确认清单；模型配置在服务端，提示词源在客户端 |
| 浏览器一概全自动归属与修复 | 默认浏览器优先，选定真实 Profile；页面检测和有限可恢复设置；权限/格式不足明示 |
| 默认所有国内地址直连 | 仅日常获准白名单直连，Claude 规则优先；专用模式保留但停用白名单 |
| FD-02 早期提及高级规则编辑 | FD-03 已收窄为用户自助维护日常直连白名单；其他受管规则由后台维护，不开放任意 YAML |
| 共享上游总量绑定用户即可限额 | 共享资源池与用户账目分开；服务节点识别用户并执行独立停用 |
| 所有流量准确归属 Claude/其他 | 首版先展示核心字节、A/B 路线和可靠进程信息，未知保留 |
| AI 生成全部每日统计 | 程序唯一分类器/字节计数形成事实，AI 附分析；保护不等待分析 |
| 普通日志可清理 | 活动监控、当前审计窗口、已生成日报不纳入默认清理 |

## 4. 阶段出口

技术样机只证明关键链路，不能称完整首版。功能内测版包含四模块真实闭环，可在声明机器上由 Owner 操作；完整 V1 试用版还应通过安装、重启、恢复、限额与保护故障场景，交给少量普通用户使用。开源公开发布在真实资源、隐私材料、第三方许可证和安装说明检查后另行执行。
